# 航空发动机叶片检测数据集

> 本仓库用于介绍航空发动机叶片检测相关图像数据集的组成、统计规模及获取方式。完整数据文件通过网盘提供，下载入口见下方”数据集下载”部分。

## 1. 数据集简介

当前统计的数据集共包含 **71,601张图像**，分为非叶片图像（N_YP）和叶片图像（YP）两部分，涉及 **15个子数据集**。 其中，N_YP 包含 10 个子数据集，共 46,165 张图像；YP 包含 5 个子数据集，共 25,436 张图像。数据集同时统计了正常图像以及缺陷或其他图像的数量，可用于了解当前数据资源的类别组成和规模。

## 6. 数据说明与使用注意事项

- N_YP 表示非叶片图像类别，YP 表示叶片图像类别。
- 本仓库当前公开的是数据集介绍和统计信息，完整图像文件通过上方网盘链接获取。
- 当前统计说明记录了图像数量及类别组成，但未提供所有子数据集的完整来源证明、授权许可、标注格式、图像分辨率及训练/验证/测试集划分信息。上述信息应以实际发布的数据文件及后续补充说明为准。
